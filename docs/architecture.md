# Architecture

## Purpose

DisciplineCoach is a Joomla component for managing disciplines, memberships, moderator roles, and knowledge sharing.

The component is designed to be independent of any specific subject area.

Examples of disciplines:

- Badminton
- Football
- Hockey
- Music
- First Aid

## Core Concepts

### Discipline

A discipline represents a domain of expertise, specialization, interest, or knowledge.

### Membership

A membership defines which discipline a user belongs to.

### Moderator

A moderator is responsible for maintaining content quality within a discipline.

### Content

Content always belongs to a discipline.

Examples:

- Exercises
- Training plans
- Documents
- Images

## Roles

- Registered User
- Moderator
- Super Administrator
